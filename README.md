
# Sarvesh S - Personal Portfolio

A responsive personal portfolio built using HTML, CSS and vanilla JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design for desktop and mobile
- Dark and light theme toggle
- Mobile navigation menu
- About and education sections
- Technical skills section
- Project and practice section
- Contact form that prepares an email
- Accessible labels and keyboard focus styles

## Project Structure

```text
sarvesh-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## How to Run

1. Download or copy the project files.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

You can also open `index.html` directly in your browser.

## Customization

- Update personal details in `index.html`.
- Add links to actual project repositories.
- Replace the sample project descriptions with completed projects.
- Add a profile photo if desired.
